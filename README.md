# 🩸 BloodLink

### Donate • Save • Connect

BloodLink is a blood donation and donor management platform designed to connect blood donors with patients quickly and efficiently.

The platform helps users find suitable blood donors, register as donors, submit blood requests, and locate nearby blood banks.

---

## 🚀 Features

- 🔎 Find blood donors
- 🩸 Become a blood donor
- 📋 Register donor details
- 🚨 Submit blood requests
- 🏥 Find blood banks
- 👥 Manage donor information
- ❤️ Simple and user-friendly interface

---

## 💻 Technologies Used

- JavaScript
- HTML5
